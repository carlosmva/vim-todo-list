Link cards to files under an Obsidian vault. Set the vault name exactly as shown in Obsidian (lower-left vault menu). Each card maps to …/notes-folder/board-slug/title-slug.md, or …/title-slug-note-id.md when two cards on the same board share the same title. Use Choose vault folder — Chrome opens a tab where you pick the same folder Obsidian uses. Linking turns on Sync mode automatically. Each Obsidian button on a card compares that note’s Markdown file with the card and updates whichever side is newer (or asks if it’s a tie). Without Sync mode and a linked folder, only the first click can create the file; later clicks open it in Obsidian (the URI cannot overwrite an existing note without creating duplicates).
