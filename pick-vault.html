Obsidian Sync

Choose Your Vault Folder

Select the vault’s root folder — the name in Obsidian’s lower-left vault menu. Do not pick the notes folder (for example ToDo) and do not pick the hidden .obsidian folder. Chrome will ask you to Allow read/write. That Allow only applies to this tab. After you return to Settings, click Allow folder access so the extension window can use the same folder. You do not choose a second folder.
